**版本**: 2026-03-27

## 三个坐标系的最关键区别

| 坐标系 | 定义 | 具体向量 | 使用位置 | 注意事项 |
|---|---|---|---|---|
| **世界系** | 固定的参考系：x 前、y 左、z 上 | $p, v, a, Re_3$ | 位置、速度、推力计算 | 所有物理计算的基础 |
| **机体系** | 随无人机一起旋转的坐标系 | $\omega$ (角速度) | 动力学控制 | **不能与世界系向量直接做叉积** |
| **SDF 梯度** | 世界系中的偏导数 | $n = [∂SDF/∂x, ∂SDF/∂y, 0]$ | 障碍感知和 CBF 约束 | **标准命名：n_x 对应 x 方向，n_y 对应 y 方向** |

---

## 关键的旋转矩阵关系

```
旋转矩阵 R: 机体 → 世界
  v_world = R @ v_body
  ω_world = R @ ω_body

反向：
  v_body = R^T @ v_world
  ω_body = R^T @ ω_world

推力方向:
  推力在世界系中 = R @ [0, 0, 1] = Re_3 = R[:, 2]
```

---

## CBF 约束的正确形式

### ✅ 正确的做法（推荐）
```python
# 在世界系计算，最后转换 A 到机体系
n = n_world           # 保持世界系
Re3 = R @ [0,0,1]    # 世界系推力方向
n_cross_Re3 = np.cross(n, Re3)  # 世界系叉积
A_world = -n_cross_Re3
A_body = R.T @ A_world  # 转换到机体系
constraint = A_body @ ω_body >= b
```

## 场景 A：左前方障碍物→右 roll

**场景**：
- 无人机在 (0, 0)
- 障碍在 (1, 0.5)（前方 1m，左方 0.5m）

**SDF 梯度**：
- n_x = ∂SDF/∂x < 0（右侧更安全）
- n_y = ∂SDF/∂y < 0（后侧更安全）
- n = [-0.707, -0.707, 0]（指向右后）

**叉积**：
n × Re3 = [-0.707, -0.707, 0] × [0, 0, 1]
        = [-0.707, 0.707, 0]

**约束矩阵**：
A_body = -R^T(n × Re3) ≈ [0.707, -0.707, 0]

**约束**：
0.707*ω_x - 0.707*ω_y >= b

**右 roll (ω_x > 0)**：
0.707*1.0 = 0.707 >= b ✓ 满足约束！

**物理效果**：
右 roll 使推力向 Y 负方向（右侧）倾斜
无人机向右加速，避开左前方障碍 ✓

## 场景 B：右前方障碍物→左 roll

**场景**：
- 无人机在 (0, 0)
- 障碍在 (1, -0.5)（前方 1m，右方 0.5m）

**SDF 梯度**：
- n_x = ∂SDF/∂x < 0（右侧更安全）
- n_y = ∂SDF/∂y > 0（前侧更安全）
- n = [-0.707, 0.707, 0]（指向左后）

**叉积**：
n × Re3 = [-0.707, 0.707, 0] × [0, 0, 1]
        = [0.707, 0.707, 0]

**约束矩阵**：
A_body = -R^T(n × Re3) ≈ [-0.707, -0.707, 0]

**约束**：
-0.707*ω_x - 0.707*ω_y >= b

**左 roll (ω_x < 0)**：
-0.707*(-1.0) = 0.707 >= b ✓ 满足约束！

**物理效果**：
左 roll 使推力向 Y 正方向（左侧）倾斜
无人机向左加速，避开右前方障碍 ✓

## SDF 梯度的详细计算

### 网格布局
```
索引：0  1  2
      3  4  5
      6  7  8

位置：(x-δ,y-δ)  (x-δ,y)    (x-δ,y+δ)
      (x,y-δ)     (x,y)      (x,y+δ)
      (x+δ,y-δ)  (x+δ,y)    (x+δ,y+δ)

g_id = g_i * 3 + g_j
  g_i: 0=x-δ, 1=x, 2=x+δ
  g_j: 0=y-δ, 1=y, 2=y+δ
```

### 梯度公式（标准命名）
```python
n_x = (SDF[7] - SDF[1]) / (2*δ)  # ∂SDF/∂x
n_y = (SDF[5] - SDF[3]) / (2*δ)  # ∂SDF/∂y
```

**检查**：梯度指向安全方向吗？
- 如果右侧 SDF 值大（右侧更安全），则 n_x > 0 ✓
- 如果后侧 SDF 值大（后侧更安全），则 n_y > 0 ✓
- 梯度指向 SDF 增加的方向，即安全方向 ✓
