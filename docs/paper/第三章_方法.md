# 第三章 方法

## 3.1 问题定义

本文研究结构化障碍环境中的无人机导航问题。环境由连续空间中的无人机动力学、静态障碍物以及目标点共同构成。无人机需要在满足动力学约束的前提下，从起点飞行至目标点，同时避免与障碍物发生碰撞。

我们将该问题建模为马尔可夫决策过程。策略输入为无人机自身状态与局部障碍观测，输出为连续控制动作。本文采用的观测由以下部分组成：

- 相对目标位置 `xyz`
- 线速度 `vxyz`
- 姿态矩阵 `R`
- 角速度 `omega`
- 地面相关状态 `floor`
- 局部障碍观测 `octomap`

动作空间采用 `omegathrust` 形式，由角速度指令与总推力共同构成。

本文的核心问题不是重新设计强化学习算法主体，而是回答：在结构化障碍环境中，如何为 RL 提供合适的导航信号，使其学习到沿可行通路推进的飞行策略。

## 3.2 欧氏目标奖励的局限性

传统目标驱动奖励通常直接基于无人机与目标点之间的欧氏距离构建，即鼓励无人机在每一步中尽可能接近终点。然而在存在偏置门、绕行通道等结构化障碍的场景中，最优动作往往并不是直线靠近终点，而是需要短时横移、绕行，甚至暂时偏离终点方向。因此，单纯的欧氏距离奖励会产生错误的优化信号，导致策略表现出直冲障碍、碰撞率高或在局部区域死锁等问题。

为解决这一问题，本文提出基于障碍拓扑结构的引导机制，将导航目标从几何接近终点转化为沿可行通路推进。

## 3.3 全局 BFS 拓扑引导

对于静态障碍环境，我们首先基于障碍占据图构建二维拓扑距离场。具体地，将静态障碍映射为二维占据栅格，并以终点所在栅格为起点进行反向广度优先搜索，得到每个可通行栅格到终点的最短可行路径长度，记为：

\[
D_{\text{global}}(x, y)
\]

该量刻画的不是终点的欧氏距离，而是在障碍物约束下，从当前位置到终点的最短可行通路长度。

考虑到无人机飞行是三维过程，我们进一步将高度误差并入引导距离，定义为：

\[
\tilde{D}_{\text{global}}(s_t)=D_{\text{global}}(x_t,y_t)+|z_t-z_g|
\]

其中，\(z_g\) 表示目标点高度。于是，全局引导奖励定义为：

\[
r_t^{\text{global}}=\lambda_g\left(\tilde{D}_{\text{global}}(s_t)-\tilde{D}_{\text{global}}(s_{t+1})\right)
\]

该奖励仅在无人机沿可行通路向目标推进时为正，当策略偏离可行通路或朝错误方向运动时则为负。与欧氏距离奖励相比，该设计能够显式反映环境拓扑信息，从而避免直线冲撞障碍的问题。

## 3.4 局部滚动 BFS 引导

尽管全局 BFS 能够提供有效的导航信号，但它依赖完整静态地图，属于较强的特权信息。为减弱这种依赖，本文进一步提出局部滚动 BFS 引导方法。

在每个时刻，首先将无人机当前位置映射到最近的可行 guidance 栅格，以其为中心截取一个局部窗口：

\[
\mathcal{W}_t
\]

窗口大小固定在有限视野范围内。在该窗口内，先从当前位置执行一次局部 BFS，得到局部可达区域。随后，仅在局部窗口的边界可达栅格中选择一个局部前沿目标 \(b_t\)。该前沿目标表示当前局部视野下最值得首先到达的出口或下一段通路节点。

为避免每一步都重新选择局部目标而导致抖动，本文引入短时保持机制：一旦选定某个局部目标，则在若干控制步内保持不变，直到满足到达、失效或超时条件后再重新选择。这样可以将局部引导从逐步贪心选择，转换为滚动时域下的短程目标跟踪。

在局部目标确定后，进一步在局部窗口内以该目标为终点构建局部 BFS 距离场，记为：

\[
D_{\text{local}}(s_t,b_t)
\]

同时，为保持总体导航方向的一致性，我们将局部目标到最终终点的剩余全局拓扑距离作为后缀项，得到最终的局部引导距离：

\[
\tilde{D}_{\text{local}}(s_t)=D_{\text{local}}(s_t,b_t)+D_{\text{suffix}}(b_t)+|z_t-z_g|
\]

对应的局部引导奖励为：

\[
r_t^{\text{local}}=\lambda_l\left(\tilde{D}_{\text{local}}(s_t)-\tilde{D}_{\text{local}}(s_{t+1})\right)
\]

该方法可以理解为一种滚动局部拓扑引导：策略在有限局部视野内朝当前前沿目标推进，同时通过后缀项保持与整体目标方向的一致性。

## 3.5 总体奖励设计

在本文中，无人机总奖励由导航引导项与基础飞行项组成：

\[
r_t = r_t^{\text{guide}} + r_t^{\text{collision}} + r_t^{\text{proximity}} + r_t^{\text{stability}}
\]

其中：

- \(r_t^{\text{guide}}\) 为导航引导项，可取欧氏目标奖励、全局 BFS 引导或局部 BFS 引导
- \(r_t^{\text{collision}}\) 为碰撞惩罚
- \(r_t^{\text{proximity}}\) 为近邻或近障碍惩罚
- \(r_t^{\text{stability}}\) 为姿态、角速度与控制平滑相关项

对于 `global_bfs` 与 `local_bfs` 模式，本文关闭原始欧氏位置奖励，仅保留基于拓扑距离进展的 guidance reward，从而避免多种导航信号同时作用导致的冲突。

## 3.6 训练方式

为保证比较公平，本文保持强化学习算法主体不变，统一采用 PPO 框架进行训练。不同方法之间仅改变导航信号的构造方式，而不改变策略网络结构、动作空间或训练流程。这样可以更清楚地分析性能差异究竟来自导航目标设计，而非算法主体变化。

因此，本文比较的三类方法分别为：

- `PPO + Euclidean Reward`
- `PPO + Global BFS Guidance`
- `PPO + Local BFS Guidance`

其中：

- `PPO + Euclidean Reward` 作为无拓扑引导基线
- `PPO + Global BFS Guidance` 作为强特权信息上界
- `PPO + Local BFS Guidance` 作为主方法，用于评估弱化特权信息后的导航能力

## 3.7 方法特点总结

本文方法的核心不在于重新设计一个新的强化学习算法，而在于为 UAV 在结构化障碍环境中的导航任务提供更合理的目标信号。其主要特点包括：

- 将导航目标从几何接近转化为可行通路推进
- 将静态障碍拓扑信息显式融入强化学习训练信号
- 通过局部滚动 BFS 机制减弱对全局特权信息的依赖
- 在三维状态下同时考虑平面通路推进与高度误差约束

总体而言，本文方法可视为一种面向结构化障碍 UAV 导航任务的拓扑感知引导框架，其重点在于目标信号与可行通路之间的一致性，而非单纯依赖欧氏距离作为导航依据。
